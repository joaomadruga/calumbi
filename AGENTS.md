# Instruções do projeto

## Preferência explícita do usuário

- Não utilizar Google Chrome para testar. Isso inclui iniciar ou controlar o Chrome em modo normal ou headless, por CDP, Playwright, Puppeteer, scripts ou ferramentas equivalentes.
- O usuário declarou em 18/10/2026 que esse uso não está autorizado. Preservar essa restrição nas próximas sessões.
- Fazer as verificações de código, tipos, build e testes automatizados sem Chrome.
